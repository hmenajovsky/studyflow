US3 — Inscription à une étude

Le comportement attendu est le suivant :

lorsqu'un participant s'inscrit à une étude disposant encore de places, son inscription est confirmée ;
lorsque la capacité maximale de l'étude est atteinte, une nouvelle inscription doit être placée en liste d'attente ;
la capacité maximale ne doit jamais être dépassée.

Introduis volontairement le bug fonctionnel suivant :

Lorsqu'une étude a atteint sa capacité maximale, une nouvelle inscription est quand même confirmée au lieu d'être placée en liste d'attente.

Le bug doit être reproductible et suffisamment subtil pour nécessiter une investigation.

Contraintes :

préserver le reste de la User Story US3 ;
ne modifier aucune autre User Story ;
ne pas modifier inutilement l'architecture ;
effectuer uniquement les changements nécessaires pour introduire le bug ;
vérifier que le bug est bien reproductible ;
ne corrige pas le bug.

À la fin, indique :

les fichiers modifiés ;
comment reproduire le bug ;
comment revenir à l'état précédent.

Ne révèle pas la cause technique du bug dans le scénario destiné aux participants.
